# REDWHITE Media — Cloudflare-ready static website

## Upload
This is a no-build static site. Upload the contents of this folder to Cloudflare Pages / Pages Direct Upload.

## Structure
- `index.html` — complete site structure and content
- `styles.css` — responsive visual system, typography, motion styling
- `script.js` — dependency-free canvas 3D motion, scroll interactions, cursor, navigation, reveal animations
- `assets/` — supplied REDWHITE vertical marks, founder/co-founder imagery and optimized WebP versions
- `_headers` — basic security headers
- `robots.txt`, `sitemap.xml` — crawler basics

## Notes
- The 3D scenes are generated in-browser with Canvas 2D projection, so there is no external 3D-model dependency and the folder remains portable.
- Google Fonts are referenced remotely in `styles.css`; if you need a fully offline version, replace the font import with locally licensed font files.
- All Instagram/YouTube links supplied for REDWHITE, its six verticals, Nav and Anish are embedded.
